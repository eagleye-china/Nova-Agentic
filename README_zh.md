## 🤔 为什么选择 nova-agentic？

- 🚀 **极致性能**：基于原生 PySide6 和 QML，拒绝笨重的 WebView。
- 🎨 **顶级颜值**：原生暗黑模式，丝滑动画，像素级布局。

## 📦 安装

```bash
pip install nova-agentic
```
